### 🚀 Projetos em destaque

Sistemas completos, com código, testes e instruções para rodar no README de cada repositório.

* **[DoseCerta: Controle Compartilhado de Medicação Familiar](https://github.com/carlosebnz/dosecerta)**
  Ajuda famílias que cuidam de idosos ou crianças a registrar os horários dos remédios sem esquecer doses e sem que dois cuidadores deem a mesma medicação. Garante a unicidade da dose no banco (constraint única + controle de concorrência), trata fusos horários com `Instant`, controla acesso por papéis e gera um link temporário de leitura para o médico consultar o histórico. Testes de concorrência com Testcontainers.
  `Java 21` • `Spring Boot` • `Spring Security` • `Angular` • `PostgreSQL` • `Flyway` • `Docker` • `GitHub Actions`

* **[PreçoBairro: Comparador Colaborativo de Preços de Supermercado](https://github.com/carlosebnz/precobairro)**
  Moradores registram preços, consultam o histórico para saber se uma promoção é real e montam uma cesta para descobrir qual mercado do bairro sai mais barato. Busca tolerante a erros de digitação com `pg_trgm`, cache com invalidação, regra anti-outlier contra preços falsos, rate limiting e Angular em produção. Usado por pessoas reais com preços da minha cidade.
  `Java 21` • `Spring Boot` • `Spring Cache` • `Angular` • `PostgreSQL` • `Testcontainers` • `Docker`
