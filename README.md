### Projeto em construção

**[DoseCerta](https://github.com/carlosebnz/dosecerta): controle compartilhado de medicação familiar**

Ajuda famílias que cuidam de idosos ou crianças a registrar os horários dos remédios sem esquecer doses e sem que dois cuidadores deem a mesma medicação. O sistema apenas registra: não recomenda doses nem substitui orientação médica.

Status: 🚧 em desenvolvimento

- [ ] Repositório e escopo definidos
- [ ] Domínio em Java puro, com testes (JUnit)
- [ ] Regra de dose duplicada, com teste de concorrência
- [ ] API REST com Spring Boot e PostgreSQL
- [ ] Login e permissões por papel
- [ ] Interface em Angular
- [ ] Docker, CI e deploy

Stack planejada: Java 21 · Spring Boot · PostgreSQL · Flyway · Angular · Docker · GitHub Actions
